# Mind dossiers

One file per thinker on the roster ([docs/THINKERS.md](../../../docs/THINKERS.md)). Each file is the single
source of truth for that persona: the persona prompt (built by `backend/thinkers/persona.py`) injects the
sections below verbatim.

Sections: Life and problems · What you cared about · How your thinking moved (worked examples) ·
Temperament and voice · Commitments and revisions · Blind spots · Misreadings to avoid · Territory · Sources.

Written in the second person ("you") because the text is read by the model as its own mind.

**Sources:** drafted from standard primary works and major scholarship. Wording is paraphrased; nothing is
presented as a direct quotation. Claims that scholars dispute are marked *(contested)*. Corrections with a
source are welcome (see [CONTRIBUTING.md](../../../CONTRIBUTING.md)).

# Mind dossiers

One file per thinker on the roster ([thinker-roster.md](../../../docs/features/thinker-roster.md)). Each file is the single
source of truth for that persona: the persona prompt in [09](../../../docs/features/09-agents-and-prompts.md#thinkers) (built by
`backend/thinkers/persona.py`) injects
the sections below verbatim.

Sections: Life and problems · What you cared about · How your thinking moved (worked examples) ·
Temperament and voice · Commitments and revisions · Blind spots · Misreadings to avoid · Territory · Sources.

Written in the second person ("you") because the text is read by the model as its own mind.

**Verification status (24 Oct 2026):** drafted from standard primary works and major scholarship, not
re-checked line by line against the sources this session. Wording is paraphrased; nothing is presented
as a direct quotation. Before production, spot-check each "Sources" entry and each dated fact. Claims
that scholars dispute are marked *(contested)*.

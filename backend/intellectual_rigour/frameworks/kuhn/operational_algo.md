# Operational Algorithm: Kuhnian Paradigm & Novelty Audit

```text
INPUT: Research Contribution R, Target Disciplinary Context
OUTPUT: Structured ThinkerOutput & ReviewArtifact

STEP 1: RECONSTRUCT CURRENT PARADIGM
  - Identify accepted baseline assumptions, standard benchmark leaderboards, consensus methodologies, and evaluation criteria.

STEP 2: LOCATE CONTRIBUTION TYPE
  - Classify the actual nature of contribution R:
      - Normal Puzzle-Solving: Extends existing methods, improves benchmark metrics by incremental margins.
      - Anomaly Resolution: Solves a recognized failure mode within current paradigm.
      - Framework Modification: Alters auxiliary assumptions while preserving foundational core.
      - Competing Paradigm: Proposes fundamentally different ontological entities, operations, and objectives.

STEP 3: ANOMALY AUDIT
  - Search for systematic anomalies, failure modes, or edge cases that current consensus approaches suppress or dismiss as "unimportant noise."

STEP 4: PARADIGM DEPENDENCE TEST
  - Ask: "Does the proposed contribution rely entirely on the current conceptual framework to make sense, or does it possess independent explanatory power?"

STEP 5: COMPETING FRAMEWORK CONSTRUCTION
  - Construct the strongest plausible alternative conceptual framing for the exact same problem space.

STEP 6: COMPARATIVE PROBLEM-SOLVING POWER
  - Compare the proposed approach vs. competing paradigm across:
      - Explanatory scope
      - Anomaly resolution capability
      - Computational / empirical burden
      - New research questions opened

STEP 7: CONTEXT-FIRST ASSIGNMENT & OUTPUT
  - If baseline paradigm specifications or historical benchmark lineages are missing:
      verdict = INSUFFICIENT_CONTEXT
      recommendation = WITHHELD_PENDING_CONTEXT
  - If the paper claims "revolutionary paradigm shift" but is merely normal puzzle-solving, or if it ignores catastrophic paradigm anomalies:
      verdict = MATERIAL_OBJECTION
  - If the contribution is accurately classified and evaluated against competing frameworks:
      verdict = NO_MATERIAL_OBJECTION
```

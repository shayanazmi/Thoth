# Modern Adaptation: Baconian Inductive Rigour in Data Science & Empirical Research

## 1. Domain Translation Matrix

| Historical Baconian Concept | Modern Scientific & AI Translation |
| :--- | :--- |
| **Tables of Presence & Absence** | Comprehensive ablation matrices, negative control groups, null hypothesis significance testing. |
| **Eliminative Induction** | Systematic ablation studies proving that component X (and not random seed / compute budget) caused the performance gain. |
| **Experimentum Crucis** | Head-to-head out-of-distribution benchmark comparisons designed where architectures make opposing failure predictions. |
| **Idols of the Tribe / Cave** | Cognitive biases, dataset collection skew, confirmation bias, lack of double-blind review. |
| **Idols of the Marketplace / Theatre** | Hype cycles, buzzwords ("super-human", "emergent reasoning"), dogmatic adherence to leaderboards. |
| **Gradual Induction Ladder** | Ensuring claims generalize only as far as representative data permits; preventing out-of-domain overreach. |

## 2. Boundaries
* Bacon's rejection of mathematics and pure deduction in discovery is not adopted; we preserve his eliminative comparative protocol and defensive cognitive bias auditing.

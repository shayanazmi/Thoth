# Modern Adaptation: Humean Causal Rigour in Modern AI & Statistics

## 1. Domain Translation Matrix

| Historical Humean Concept | Modern Statistical & Causal Inference Translation |
| :--- | :--- |
| **Constant Conjunction vs. Necessary Connection** | Correlation vs. Causation; Pearl's Ladder of Causation (Association $P(y|x)$ vs. Intervention $P(y|do(x))$ vs. Counterfactuals). |
| **Inferential Jump** | Claiming an architecture "understands" or "causes" performance gains based solely on observational validation loss curves. |
| **Alternative Causal Hypotheses** | Confounding, collider bias, Berkson's fallacy, omitted variable bias, spurious correlations. |
| **Problem of Induction** | Distribution shift, dataset covariate shift, out-of-distribution generalization failure. |
| **Proportioning Belief to Evidence** | Bayesian shrinkage, reporting confidence intervals, avoiding overclaiming causal mechanisms from correlational benchmarks. |

## 2. Boundaries
* Modern causal graphs (Judea Pearl, Donald Rubin) provide mathematical tools for identification under assumptions that Hume did not possess; this framework uses those tools to enforce Hume's foundational skeptical discipline.

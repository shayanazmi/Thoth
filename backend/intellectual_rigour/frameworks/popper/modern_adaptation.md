# Modern Adaptation: Popperian Rigour in 21st Century Science & AI

## 1. Domain Translation Matrix

| Historical Popperian Concept | Modern Scientific & Machine Learning Translation |
| :--- | :--- |
| **Falsifiability & Demarcation** | Out-of-distribution (OOD) stress tests, adversarial evaluation, hold-out benchmark verification. |
| **Risky Predictions** | Pre-registered hypotheses, blind prospective validation, predicting unexpected edge-case failure modes before empirical testing. |
| **Ad-Hoc Immunization Stratagems** | Post-hoc dataset filtering, unreported metric cherry-picking, p-hacking, retrospective overfitting without ablation tests. |
| **Severe Testing** | Stress-testing models against adversarial perturbations, noise injection, and contrasting against strong null baselines. |
| **Corroboration** | Bounded empirical reliability on specified benchmark distributions; explicit rejection of "proven" or "general intelligence" claims. |

## 2. Boundaries & Non-Doctrinal Scope
* Modern statistical modeling often utilizes Bayesian posteriors and empirical risk minimization. Popper's strict deductive falsification is translated here as **epistemic stress-testing**: ensuring models specify failure conditions, test counter-hypotheses, and explicitly state conditions under which performance gains evaporate.

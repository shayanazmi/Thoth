# Code of conduct

Thoth is about honest inquiry, and the project is run the same way.

- Be respectful and assume good faith. Criticise ideas, not people.
- Disagreement is welcome when it comes with reasons and evidence.
- No harassment, discrimination or personal attacks of any kind.

Maintainers may remove comments, commits or contributions that break these rules. Report concerns to the
maintainer privately through GitHub.
